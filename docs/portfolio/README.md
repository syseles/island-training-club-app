# Portfolio assets

Hero images and screenshots used for external profiles (Upwork, GitHub, internal ITC materials).

## Recommended hero

`hero.png` — responsive split (desktop + mobile) of the Schedule page showing the pooled HYROX row.

## Capture checklist

1. Run `python3 -m http.server 4173` from the repo root.
2. Open `http://127.0.0.1:4173/app/` in a 1440px browser, navigate to Schedule, capture.
3. Resize to 390px, navigate to the same week, capture.
4. Stitch in Figma or Shottr.
5. Export as PNG, 1600×1200, ≤ 1.5 MB.

## File naming

- `hero.png` — single hero image.
- `<feature>-mobile.png` — feature-specific mobile shot.
- `<feature>-desktop.png` — feature-specific desktop shot.

Keep all images under 2 MB for portfolio upload limits.
